# LinguaBatch

A marketing / landing site for **LinguaBatch**, an AI document-translation product
that translates entire PDFs, Excel sheets and PowerPoint presentations in the
browser — no copy-paste — turning manual translation into automated, scalable
document workflows.

## Features

- Animated marketing landing page: hero, problem/solution, interactive demo,
  feature and business-case sections, vision and call-to-action.
- A simple blog section (`app/blog`).
- Section-level analytics tracking via Vercel Analytics.
- SEO essentials: `sitemap.ts`, `robots.ts` and rich Open Graph metadata.

## Tech

- Next.js 16 (App Router) with React 19 and TypeScript.
- Tailwind CSS v4, Framer Motion animations, Lucide icons, react-markdown.
- Vercel Analytics.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
npm start
```
